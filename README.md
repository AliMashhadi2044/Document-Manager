# سامانه مدیریت اسناد کارپردازی

سامانه سازمانی فارسی/راست‌چین برای مدیریت چرخه کامل اسناد مالی کارپردازی: ایجاد سند،
ثبت فاکتورهای چندساختاره، محاسبات مالی دقیق ریالی، گردش کار ثبت و بایگانی، بازخورد ناظر،
و تولید خروجی‌های چاپی قابل طراحی (گزارش مالیات و گزارش‌های آینده).

> **وضعیت فعلی: فازهای ۰ تا ۸ تکمیل‌شده.**
> این یادداشت تا فاز ۷ نوشته بود «هنوز هیچ کدی پیاده‌سازی نشده است» — که از فاز ۱ به
> بعد درست نبود و اینجا تصحیح می‌شود.
>
> ساخته‌شده: زیرساخت و سیستم طراحی، اطلاعات پایه و فروشندگان، اسناد و فاکتورها با
> محاسبات مالی ریالی و snapshot و ثبت نهایی تراکنشی، فاکتورهای اختصاصی انشعابات و
> سوخت، بایگانی با فایل امن و بازخورد ناظر و اعلان، گزارش مالیات با موتور قالب و
> خروجی چاپ/Excel/PDF، طراح بصری قالب گزارش با نسخه‌بندی و انتشار، و گزارش‌گیری
> عمومی با فیلترساز و نمای ذخیره‌شده و خروجی صف‌شده و داشبورد.
>
> در دست اقدام: سخت‌سازی و انتشار (فاز ۹).
> وضعیت دقیق هر فاز، همراه با نقص‌های پیداشده و بدهی‌های باقی‌مانده، در
> [docs/13-phasing.md](docs/13-phasing.md) ثبت است.

## راه‌اندازی محلی

محیط: Node.js 24.12، npm 11.6، Docker 29.2، Git 2.40. PostgreSQL از طریق Docker
Compose تأمین می‌شود. دستورها و آزمون‌های زنده هر فاز در
